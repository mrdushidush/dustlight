- **Tested on one PC** (NVIDIA RTX 5060 Ti, Windows 11, 3440×1440). Other graphics cards
  should work (the renderer is plain DirectX 11, and its HD picture passes the same checks
  on Microsoft's software renderer), but haven't been tried yet. Please report problems with your
  `debug.log` (start the game with the environment variable `DEBUGACTIVE=log`).
- **The 4x pack hasn't been seen on a real 4K screen yet.** It passes the same checks in a
  3440×1920 window on the test PC.
- **Tested with the Epic Games version of Fallout 2, in English, French and German.** The GOG
  and Steam versions haven't been tried yet; any art of theirs that differs is shown in the
  original resolution.
- **Interface pieces with translated text** (about 90 buttons and labels in the German and
  French versions) are shown in the original resolution; all other art is the same in
  every language and is HD.
- **Without the High Resolution Patch's files** (`f2_res.dat`) in your game folder, the
  interface bar is narrower, with black on both sides. The game itself runs the same.
- **Art changed by mods** is shown in the original resolution.
- **Movies** play as in the original.
- **Windows may warn** that the exe is from an unknown publisher (it isn't signed).
